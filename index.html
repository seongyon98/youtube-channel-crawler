YouTube 채널 수집기

키워드로 교육·강의 목적의 한국 유튜브 채널을 찾아 연락처까지 정리해 줍니다.

처음 사용하시나요? — 먼저 읽어보세요

이 프로그램이 하는 일

  1. 입력한 키워드로 유튜브에서 채널을 검색합니다.
  2. 한국 채널 / 강의·교육 채널 / 최근 활동 / 연락처 있음 조건으로 걸러냅니다.
  3. 남은 채널의 이름·구독자수·연락처를 파일로 정리해 줍니다.

시작하기 전에 꼭 알아두실 것

1. YouTube API 키가 반드시 필요합니다 (무료)

구글 계정 하나당 키 1개로 생각하시면 됩니다. 키를 더 늘리려면 다른 구글 계정에서 새로 발급받아야 합니다.

2. API 키 1개 = 하루 키워드 3~5개

키워드 1개당 최대 100개 채널을 수집하는데, 그 정도가 키 하나의 하루 한도에 딱 맞습니다. 더 넣으면 뒷부분 키워드는 한도가 떨어져 수집되지 않습니다.

3. 하루에 한 번만 실행하세요

사용 한도는 하루 단위로 초기화됩니다. 같은 날 여러 번 돌려도 그날 모을 수 있는 총량은 늘지 않습니다.

4. 키워드를 많이 돌리고 싶다면

키워드 3~5개씩 담은 텍스트 파일을 여러 개 만들고, 파일 개수만큼 API 키를 준비하세요. 2단계에서 파일을 여러 개 한 번에 올릴 수 있습니다.

예) 키워드 파일 3개 → 키워드 9~15개 → API 키 3개 필요 → 구글 계정 3개 필요

5. 같은 채널이 두 번 나오지 않습니다

한 번 확인한 채널은 기록해 두기 때문에, 계속 사용하시면 처음이 결과가 가장 많고 이후에는 새로 생긴 채널만 쌓여 점점 줄어듭니다. 고장이 아니라 정상입니다.

기록은 사용하는 사람마다 따로 쌓입니다. 다른 분이 같은 키워드로 돌리면 그분에게는 처음이므로 같은 채널이 나올 수 있습니다.

이어서 쓰고 싶다면 → 쓰던 PC의 data 폴더를 통째로 복사해 덮어쓰면 기록이 이어집니다.

6. OpenAI 키는 선택입니다

넣으면 AI가 영상 자막까지 확인해 판별 정확도가 크게 올라가지만 사용료가 발생합니다. 비워두면 무료로 동작하며, 대신 관련 없는 채널이 조금 더 섞입니다.

7. 수집 결과는 사람의 검수가 반드시 필요합니다

AI가 걸러내긴 하지만 100% 강의 채널이라고 볼 수 없습니다. 연락처도 채널 소개글에서 자동으로 뽑아낸 것이라, 담당자가 아닌 주소가 섞여 있을 수 있습니다.

실제로 연락하시기 전에 반드시 채널을 직접 확인해 주세요.

1 API 키 등록

입력한 키는 이 프로그램 안에만 저장되며, 다른 곳으로 전송되지 않습니다.

키를 여러 개 넣으면 하루 수집량이 그만큼 늘어납니다. (키 1개당 하루 약 10,000 units)
AI 검수를 켜면 강의 채널 판별 정확도가 크게 올라가지만, OpenAI 사용료가 발생합니다.
API 키 발급 방법 보기
  1. YouTube — Google Cloud Console에서 프로젝트 생성 → YouTube Data API v3 사용 설정 → 사용자 인증 정보에서 API 키 만들기
  2. OpenAI — platform.openai.com에서 API 키 생성 (결제 수단 등록 필요)

2 키워드 입력

키워드 목록 하나가 API 키 하나의 하루치입니다. 목록 번호와 키 번호가 짝을 이룹니다.

키워드 1개당 최대 100개 채널을 수집하도록 설정되어 있습니다. 이 설정에서는 목록 하나에 3~5개가 하루 한도에 알맞습니다.
