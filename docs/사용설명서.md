# 사용설명서

브라우저 UI로 쓰는 방법을 처음부터 끝까지 설명합니다. 프로그래밍 지식이 없어도 따라 할 수 있도록 쓰였습니다.

---

## 어떤 프로그램인가요?

키워드를 입력하면 그 주제를 다루는 한국 유튜브 채널을 찾아, 강의·교육 목적의 채널만 골라내고 공개된 연락처(이메일, 전화번호 등)까지 정리해 주는 프로그램입니다.

모든 작업은 내 PC에서만 이뤄집니다. 수집 결과와 API 키는 외부로 전송되지 않습니다.

---

## 꼭 알아두실 3가지

### 1) API 키 1개 = 하루 키워드 3~5개 (기본 설정 기준)

API 키 하나로 하루에 모을 수 있는 양은 대략 채널 300~500개입니다. 기본 설정이 "키워드당 최대 100개"이므로 3~5개가 알맞습니다. 더 넣으면 뒷부분 키워드는 한도가 떨어져 수집되지 않습니다.

이 개수는 [3단계 수집 조건]에서 바꿀 수 있습니다. 줄이면 키워드를 더 넣을 수 있고, 늘리면 더 적게 넣어야 합니다.

| 키워드당 최대 채널 수 | 목록 하나에 넣을 키워드 |
|---|---|
| 50개 | 6~10개 |
| 100개 (기본값) | 3~5개 |
| 200개 | 2~3개 |

화면의 2단계 안내가 현재 설정에 맞춰 자동으로 바뀌니 그대로 따르시면 됩니다.

### 2) 하루에 한 번만 실행하세요

사용 한도는 하루 단위로 초기화됩니다. 같은 날 여러 번 돌려도 그날 모을 수 있는 총량은 늘지 않습니다.

### 3) 키워드를 많이 돌리려면 API 키가 그만큼 필요합니다

키워드 3~5개씩 담은 파일을 여러 개 만들고, 파일 수만큼 키를 준비하세요. API 키는 구글 계정 하나당 1개로 생각하시면 되므로, 키를 늘리려면 다른 구글 계정이 필요합니다.

```
키워드 파일 3개  →  키워드 9~15개  →  API 키 3개 필요  →  구글 계정 3개 필요
```

> **같은 채널은 두 번 나오지 않습니다. 단, 이 폴더 안에서만입니다.**
>
> 한 번 확인한 채널은 이 폴더의 `data` 안에 기록해 둡니다.
> - 같은 컴퓨터에서 계속 실행하면: 처음이 가장 많고, 이후에는 새로 생긴 채널만 쌓여 결과가 점점 줄어드는 것이 정상입니다.
> - 다른 사람이 다른 컴퓨터에서 새로 받아 쓰면: 기록이 없으므로 처음부터 다시 수집하며, 같은 채널이 중복으로 나올 수 있습니다.
> - 이어서 쓰고 싶다면 쓰던 PC의 `data` 폴더를 통째로 복사해 덮어쓰세요.

## 준비물

### 1) 파이썬 (Python)

설치되어 있지 않다면 <https://www.python.org/downloads/> 에서 내려받으세요.
설치 화면 맨 아래 **"Add python.exe to PATH"** 를 반드시 체크해야 합니다.

### 2) YouTube Data API 키 (필수)

1. <https://console.cloud.google.com/> 접속
2. 프로젝트 만들기 → "YouTube Data API v3" 검색 후 **[사용]** 클릭
3. [사용자 인증 정보] → [사용자 인증 정보 만들기] → [API 키]

### 3) OpenAI API 키 (선택)

<https://platform.openai.com/api-keys> 에서 발급합니다.
넣으면 강의 채널 판별 정확도가 크게 올라갑니다. 비워두면 AI 검수 없이 동작하며 사용료가 발생하지 않습니다.

## 실행 방법

윈도우에서는 **`run_web_ui.bat`** 파일을 더블클릭하세요. 다른 환경에서는 이 폴더에서 아래 명령을 실행합니다.

```bash
python app.py
```

- 검은 창이 뜨고, 잠시 후 브라우저가 자동으로 열립니다.
- 처음 실행할 때는 필요한 프로그램을 설치하느라 1~2분 걸릴 수 있습니다.
- 브라우저가 안 열리면 주소창에 <http://127.0.0.1:5000> 을 직접 입력하세요.

> 사용하는 동안 검은 창을 닫지 마세요. 창을 닫으면 프로그램이 종료됩니다.

### 화면이 너무 밝거나 어두울 때

오른쪽 위 **[시스템] [밝게] [어둡게]** 버튼으로 바꿀 수 있습니다. 기본값은 [시스템]이며 운영체제 설정을 따릅니다. 한 번 고르면 다음에 열 때도 유지됩니다.

## 사용 순서

### [1단계] API 키 등록

발급받은 키를 입력합니다. 키를 여러 개 넣으면 하루 수집량이 늘어납니다.

### [2단계] 키워드 입력

키워드 목록 하나가 API 키 하나의 하루치입니다. 키워드 목록 1 ↔ API 키 1, 키워드 목록 2 ↔ API 키 2 순서로 짝을 이룹니다.

**키워드 적는 법** — 반드시 한 줄에 하나씩 적습니다.

| ✅ 이렇게 | ❌ 이렇게 하지 마세요 |
|---|---|
| 파이썬 자동화 | 파이썬 자동화, AI 에이전트 |
| AI 에이전트 | 블렌더/모션그래픽 |
| 블렌더 | "프리미어 프로" |

- 쉼표(`,`)나 빗금(`/`)이 아니라 줄바꿈(Enter)으로 구분합니다.
- 따옴표나 특수기호는 넣지 마세요. 유튜브에 검색하듯 그대로 적습니다.
- 단어 사이 띄어쓰기는 괜찮습니다. (예: `생성형 AI 실무`)
- 빈 줄은 무시되고, 중복된 키워드는 하나만 남습니다.
- 텍스트 파일로 만들 때도 형식은 같습니다. 메모장에 한 줄에 하나씩 적고 `.txt`로 저장하세요. (한글이 깨지면 저장 시 인코딩을 UTF-8로 선택)

목록 칸에 직접 입력하거나 **[파일 불러오기]** 로 텍스트 파일을 넣습니다. **[텍스트 파일 불러오기]** 에서 파일을 여러 개 한 번에 선택하면 파일 하나가 목록 하나가 되고, 부족한 API 키 칸도 자동으로 늘어납니다. (파일 이름 순서대로 목록 1, 2, 3...에 들어갑니다)

> **권장: 목록 하나에 키워드 3~5개**
> 키워드 1개당 최대 100개 채널을 수집하는데, 실제 운영해 보니 이 정도가 API 키 하루 한도에 가장 잘 맞았습니다. 5개를 넘으면 화면에 주황색으로 표시됩니다.

입력이 끝나면 **[설정 저장]** 을 누르세요.

### [3단계] 수집 조건 (선택 — 그대로 두셔도 됩니다)

어떤 채널을 남길지 정하는 값을 화면에서 조절할 수 있습니다.

| 항목 | 설명 |
|---|---|
| AI 정밀 검수 사용 | OpenAI 검수를 켜고 끕니다 |
| 키워드당 최대 채널 수 | 많을수록 API를 많이 씁니다 (기본 100개). 이 값을 바꾸면 2단계의 '목록당 적정 키워드 수' 안내도 함께 바뀝니다 |
| 최근 활동 기간 | 최근 N개월 안에 영상을 올린 채널만 (기본 6개월) |
| 고급 설정 | 한국 채널만 / 연락처 필수 / 강의 채널만 / AI 검수 모델 이름 등 |

AI 검수 모델은 직접 입력합니다. OpenAI 모델은 수시로 추가되거나 중단되므로, 목록으로 고르지 않고 이름을 직접 적도록 했습니다. 현재 쓸 수 있는 모델 이름은 OpenAI 문서에서 확인하세요. (기본값: `gpt-4o`)

잘 모르시겠으면 손대지 마세요. 바꿨다가 되돌리고 싶으면 **[기본값으로 되돌리기]** 를 누르면 처음 상태로 돌아갑니다.

### [4단계] 수집 실행

**[수집 시작]** 을 누르면 진행 상황이 실시간으로 표시됩니다. 키워드 수에 따라 수 분에서 수십 분이 걸립니다. 실행 중에는 브라우저 창과 검은 창을 닫지 마세요.

### [5단계] 결과 내려받기

- **이번 신규만 받기** — 이번 실행에서 새로 찾은 채널만 (JSON)
- **전체 결과 받기** — 지금까지 모은 전체 결과 (ZIP)

---

## 결과 파일 보는 법

채널 하나당 아래 정보가 들어 있습니다.

| 항목 | 의미 |
|---|---|
| `title` | 채널 이름 |
| `channel_url` | 채널 주소 |
| `subscriber_count` | 구독자 수 |
| `email` / `phone` | 연락처 |
| `search_keyword` | 어떤 키워드로 찾았는지 |
| `priority_review` | "문의/강연/협업" 같은 단어가 있으면 `true` |

JSON 파일은 메모장으로도 열리지만, 표로 보시려면 엑셀에서 **[데이터] → [데이터 가져오기] → [JSON]** 을 이용하세요.

## 자주 있는 문제

**Q. "파이썬이 설치되어 있지 않습니다" 라고 나옵니다.**
A. 위 [준비물] 1번을 따라 설치하세요. 이미 설치했다면 "Add python.exe to PATH"를 체크했는지 확인하고, 파이썬을 다시 설치해 보세요.

**Q. "YouTube API 키가 올바르지 않습니다" 라고 나옵니다.**
A. 키를 복사할 때 앞뒤 공백이 섞이지 않았는지 확인하세요. Google Cloud에서 "YouTube Data API v3"를 [사용] 했는지도 확인이 필요합니다.

**Q. "오늘 쓸 수 있는 API 한도를 모두 사용했습니다"**
A. 키 1개당 하루 사용량이 정해져 있습니다. 내일 다시 실행하거나, 1단계에서 키를 추가로 등록하세요.

**Q. "키워드 목록이 N개인데 API 키는 M개입니다" 라고 나옵니다.**
A. 목록 하나를 처리하려면 API 키 하나가 필요합니다. 1단계에서 [+ 키 추가]로 키를 더 등록하거나, 목록 수를 줄이세요.

**Q. 키워드를 하루에 몇 개나 넣을 수 있나요?**
A. API 키 1개당 3~5개를 권장합니다. 그보다 많이 넣으면 하루 한도에 걸려 뒷부분 키워드가 수집되지 않을 수 있습니다.

**Q. 수집된 채널이 너무 적습니다.**
A. 이 프로그램은 "한국 / 강의 채널 / 연락처 있음 / 최근 6개월 활동" 조건을 모두 만족하는 채널만 남깁니다. 조건이 까다로워 결과가 적을 수 있습니다.

**Q. 이미 수집한 채널이 또 나오나요?**
A. 아닙니다. 한 번 확인한 채널은 기록해 두고 다시 수집하지 않습니다.

## 주의사항

> **수집 결과는 사람의 검수가 반드시 필요합니다.**
> AI가 걸러내긴 하지만 100% 강의 채널이라고 볼 수 없습니다. 연락처도 채널 소개글에서 자동으로 뽑아낸 것이라, 담당자가 아닌 주소가 섞여 있을 수 있습니다. 실제로 연락하시기 전에 반드시 채널을 직접 확인해 주세요.

- 수집 결과에는 채널 운영자의 이메일, 전화번호 등 **개인정보가 포함됩니다.** 관련 법령과 소속 조직의 개인정보 취급 방침에 따라 관리하고, 동의 없는 광고성 메일 발송에 사용하지 마세요.
- OpenAI API 키를 등록하면 사용량만큼 요금이 발생합니다.
- `.env` 파일에는 입력하신 API 키가 그대로 저장됩니다. 이 폴더를 다른 사람에게 전달할 때는 `.env` 파일을 지우고 전달하세요.

## 폴더 구성

| 경로 | 설명 |
|---|---|
| `run_web_ui.bat` | Windows 실행 파일 (더블클릭) |
| `app.py` | 프로그램 본체 (브라우저 UI 서버) |
| `index.html` | 브라우저에 표시되는 화면 |
| `src/` | 내부 처리 코드 |
| `keywords/` | 입력한 키워드가 저장되는 곳 (`keywords_1.txt` = API 키 1번이 담당하는 목록) |
| `data/` | 수집 결과가 저장되는 곳 |
| `logs/` | 실행 기록 |
| `.env` | API 키 (설정 저장 시 자동 생성) |
